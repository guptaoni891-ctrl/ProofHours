How verification works

  1. 1
    University accredits an NGO

    The admin registers the coordinator's wallet. Unregistered wallets are refused.

  2. 2
    NGO signs the hours

    Only a salted fingerprint of the fake student ID goes on-chain, never a name or real ID.

  3. 3
    The contract enforces the rules

    Hours must be within the event's limit, one record per student per event, and fixes are new entries.

  4. 4
    Anyone verifies, with no wallet

    The auditor's browser recomputes the fingerprint and reads the full trail.

Blockchain transparency

Stored on the blockchain

  • Accredited coordinator wallets and org labels
  • Events with their maximum hours
  • Append-only records: hours, issuer, time, corrections
  • Salted fingerprints only

Never stored on the blockchain

  • Student names or real IDs
  • Secret salts
  • Any personal data
